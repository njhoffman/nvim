*__helpfiles.txt* Template for making local helpfiles

Only the first line is really important.
                                                    *template-settings*

Tag names for in between * asterisks * (cannot have duplicates!)

Special highlighting occurs with words in <angle-brackets>, {braces}, or
  keycodes (CTRL-X ALT-X META-X) or `grave marks`

Reference other headers with | pipes | - |add-local-help| - |write-local-help|

 Note:              NOTE:                 Notes:
  WARNING               WARNING:              Warning:
  DEPRECATED            DEPRECATED:           Deprecated:
  https://www.google.com

Example settings section using Lua callback: >lua
  vim.api.nvim_create_autocmd({"BufEnter", "BufWinEnter"}, {
    pattern = {"*.c", "*.h"},
    callback = function(ev)
    print(string.format('event fired: %s', vim.inspect(ev)))
    end
  })
<
To use syntax use right arrow (>) plus syntax name:  >bash
  myvar=$(ls -alh | grep -r)
<
Close with (<) or automatically any line starting at column 1
